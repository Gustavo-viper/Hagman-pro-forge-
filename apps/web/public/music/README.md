# Temas dos universos (MP3)

Coloque aqui `<slug-do-universo>.mp3` (ex.: `harry-potter.mp3`) e registre a faixa em
`src/lib/music/tracks.ts` (título, crédito e `version`, aumentada sempre que o arquivo mudar).

Só use músicas que a Forge Studios tem direito de usar (produção própria, licença ou autorização
por escrito). Sem arquivo, ou se ele falhar, o universo toca a trilha original sintetizada.
