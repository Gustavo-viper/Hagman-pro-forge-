# Hangman Pro v1 — Forge Studios

Protótipo jogável em HTML/CSS/JavaScript.

Inclui:
- tela inicial gamer responsiva
- categorias e dificuldade
- partida funcional
- teclado virtual
- tentativas e vitória/derrota
- XP, coins, nível e sequência
- missões, ranking local e loja visual

Abra `index.html` no navegador ou use Live Server no VS Code.

Próxima etapa: Supabase para login, perfil, salvamento, ranking global, conquistas, missões diárias e inventário.
